# Poziome logo Critical Error

Logo jest niezależne od estetyki Dornogalu. TWW i Dornogal dotyczą alternatywnej grafiki oraz kolorystyki całej strony; obecna szata pozostaje jako opcja.

Koncepcje PNG z przezroczystym tłem wygenerowane wbudowanym imagegen. Napis w jednej linii, mały znak, proporcje do nagłówka strony. Nie wdrożono żadnej propozycji na stronie.
